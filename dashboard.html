Import Leads

Upload an Excel (.xlsx) or CSV file to bulk-import leads

📍 Step 1 — Choose Target Branch

Select which branch these leads belong to before uploading the file. All imported leads will be assigned to this branch automatically.

💡 Branch Managers importing their own leads don't need to select — their branch is set automatically.

📂

Drag & drop your file here

Supports Excel (.xlsx, .xls) and CSV — or click to browse

Map your spreadsheet columns to the correct lead fields, then click Import.

Preview (first 5 rows)

Import Tips

  • First row must be column headers (e.g. "First Name", "Email", "Phone")
  • Supported status values: new, contacted, qualified, proposal, won, lost
  • Emails must be valid — duplicate emails will still import (you can deduplicate later)
  • Lead value should be a number (e.g. 5000 not $5,000)
  • All imported leads are assigned to the current branch by default
  • Sensitive data is encrypted at rest in Supabase — only authorised users can view it

Filter Before Export

Export Tips

  • Leave all filters blank to export all your leads
  • Branch Managers will only export leads from their branch
  • Client Consultants will only export their assigned leads
  • Excel format is best for sharing with management
  • CSV format works with any spreadsheet app
